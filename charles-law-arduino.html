Ⅵ. 기체의 성질 · 샤를의 법칙

아두이노로 직접 재는 온도와 기체 부피의 관계

아두이노 우노에 온도 센서와 초음파 센서를 연결해 실제 실험 장치를 만들고, 노트북과 USB로 직접 연결해서 실시간 측정값을 받아와요. 물의 온도를 바꿔가며 기체(공기)의 부피가 어떻게 달라지는지 데이터로 확인해 보세요.

개념샤를의 법칙
압력이 일정할 때, 일정량의 기체의 부피는 온도가 높아지면 커지고 온도가 낮아지면 작아진다. 이때 기체의 부피는 절대온도(켈빈온도, K = 섭씨온도 + 273)에 비례한다. 이를 샤를의 법칙이라고 한다.
탐구온도에 따른 기체 부피 변화 측정하기
목표: 아두이노 센서로 온도와 기체의 부피(비례값)를 직접 측정하여, 온도와 기체 부피 사이의 관계를 그래프로 확인할 수 있다.
준비물
아두이노 우노LM35 온도센서초음파센서(HC-SR04) 삼각플라스크 + 고무풍선(또는 큰 주사기)얼음물·상온수·미온수·뜨거운 물 브레드보드·점퍼선USB 케이블노트북(크롬/엣지)
과정
  1. 아래 회로도대로 온도센서·초음파센서를 아두이노에 연결하고, 코드를 업로드한다.
  2. 삼각플라스크 입구에 풍선을 씌우고, 풍선 꼭대기를 향하도록 초음파 센서를 고정한다. 온도센서는 플라스크 옆(또는 담그는 물 속)에 둔다.
  3. USB로 노트북과 아두이노를 연결하고, 이 페이지에서 "아두이노 연결하기"를 누른다.
  4. 플라스크를 얼음물 → 상온수 → 미온수 → 뜨거운 물 순서로 옮기며, 온도가 안정될 때마다 "현재 값 기록하기"를 눌러 표에 데이터를 쌓는다.
  5. 최소 4개 이상의 데이터를 기록하고, 자동으로 그려지는 그래프에서 온도와 부피(거리)의 관계를 확인한다.
⚠️ 뜨거운 물을 다룰 때는 화상에 주의하고, 선생님의 지도에 따라 실험하세요. 풍선이 너무 많이 부풀면 터질 수 있으니 플라스크 입구에 느슨하게 씌워주세요.

/*
  샤를의 법칙 실험 - 온도 & 거리(기체 부피 비례값) 측정 스케치
  LM35 온도센서   OUT -> A0,  VCC -> 5V,  GND -> GND
  HC-SR04 초음파  TRIG -> 9,  ECHO -> 10, VCC -> 5V,  GND -> GND
  0.5초마다 "온도,거리" 형식으로 시리얼 출력 (보드레이트 9600)
*/
const int TEMP_PIN = A0;
const int TRIG_PIN = 9;
const int ECHO_PIN = 10;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

float readTemperature() {
  int raw = analogRead(TEMP_PIN);
  float voltage = raw * (5.0 / 1023.0);
  return voltage * 100.0; // LM35: 10mV = 1도
}

float readDistanceCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long duration = pulseIn(ECHO_PIN, HIGH, 30000);
  if (duration == 0) return -1;
  return duration * 0.0343 / 2.0;
}

void loop() {
  float t = readTemperature();
  float d = readDistanceCm();
  Serial.print(t, 2);
  Serial.print(",");
  Serial.println(d, 2);
  delay(500);
}
