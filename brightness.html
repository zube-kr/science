Ⅶ. 별과 우주 · 배움활동

별의 밝기가 다른 까닭은

빛의 밝기와 거리의 관계를 설명하고, 겉보기 등급과 절대 등급으로 별까지의 거리를 비교할 수 있다. 아래 시뮬레이션으로 탐구한 뒤, 표와 질문에 답해 제출하세요.

1실험하기 · 거리에 따른 빛의 밝기 변화

종이컵에 검은색 종이를 붙이고 바닥 가운데에 정사각형 구멍을 뚫어 휴대 전화 손전등에 붙인다. 손전등 빛을 모눈종이에 비추면서 휴대 전화를 앞뒤로 움직여 보자.

  1. 종이컵에 검은색 종이를 붙이고, 종이컵 바닥의 가운데에 정사각형의 구멍을 뚫는다.
  2. 종이컵을 휴대 전화의 손전등 부분에 붙인다.
  3. 휴대 전화의 손전등 기능을 켜고, 종이컵 바닥의 구멍으로 나오는 빛을 모눈종이에 비춘다.
  4. 휴대 전화를 앞뒤로 움직여 빛이 모눈종이의 격자 모양 한 칸, 네 칸, 아홉 칸을 비출 때, 모눈종이와 휴대 전화 사이의 거리를 각각 측정한다.

아래 버튼으로 거리를 1배~4배로 늘려 보면서, 빛을 받는 넓이와 밝기가 어떻게 달라지는지 시뮬레이션으로 확인해 보자.

빛을 받는 넓이: 1칸 (한 변 1칸) 상대적 밝기: 1배 (기준)
밝기 100%

※ 실제 수업에서는 자·모눈종이로 직접 측정한 값을 아래 3번 표에 입력하세요. 이 시뮬레이션은 개념 이해를 돕기 위한 것입니다.

+아두이노 실험 · 조도 센서로 빛의 밝기 직접 재기

위 실험에서는 빛이 비추는 넓이를 쟀다면, 이번에는 아두이노와 CDS 조도 센서로 빛의 밝기를 직접 측정해 보자. 손전등과 센서 사이의 거리를 바꿔 가며 기록하면 표와 그래프가 자동으로 그려진다.

준비물
  • 아두이노 UNO, USB 케이블, 브레드보드, 점퍼선
  • CDS 조도센서 + 10kΩ 저항 (또는 CDS 조도센서 모듈)
  • 휴대 전화 손전등, 자(줄자)
  • (선택) 초음파센서 — 거리를 자동으로 잴 때

/*
  별의 밝기가 다른 까닭은 - 거리에 따른 빛의 밝기 측정 스케치
  ------------------------------------------------------------
  CDS 조도센서(부품): 5V - CDS - A0 - 10kΩ 저항 - GND
    (조도센서 모듈이면  S -> A0,  가운데(+) -> 5V,  - -> GND)
  (선택) HC-SR04 초음파센서: VCC -> 5V, GND -> GND, TRIG -> 9, ECHO -> 10
    → 손전등(휴대 전화)까지의 거리를 자동으로 잴 때만 연결합니다.

  0.2초마다 "센서값,거리" 형식으로 시리얼 출력 (보드레이트 9600)
    센서값: 0~1023 (부품 회로에서는 밝을수록 커짐)
    거리  : cm, 초음파센서가 없거나 잴 수 없으면 -1
*/
const int LIGHT_PIN = A0;
const int TRIG_PIN = 9;
const int ECHO_PIN = 10;

void setup() {
  Serial.begin(9600);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

// 잡음을 줄이려고 10번 읽어 평균을 낸다
int readLight() {
  long sum = 0;
  for (int i = 0; i < 10; i++) {
    sum += analogRead(LIGHT_PIN);
    delay(2);
  }
  return sum / 10;
}

float readDistanceCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long duration = pulseIn(ECHO_PIN, HIGH, 25000);
  if (duration == 0) return -1;
  return duration * 0.0343 / 2.0;
}

void loop() {
  int light = readLight();
  float d = readDistanceCm();
  Serial.print(light);
  Serial.print(",");
  Serial.println(d, 1);
  delay(200);
}
  1. 교실을 어둡게 하고, CDS 센서가 손전등 쪽을 향하도록 세워 고정한다.
  2. 아두이노 연결하기를 누르고, 손전등을 끈 채로 배경 빛 재기를 누른다.
  3. 손전등을 켜고 센서 정면에서 10 cm 떨어뜨린 뒤 거리를 입력하고 현재 값 기록하기를 누른다.
  4. 15 cm, 20 cm, 25 cm, 30 cm, 40 cm… 거리를 늘려 가며 같은 방법으로 기록한다. (손전등 방향은 항상 센서 정면!)

※ 빛의 세기는 CDS 센서의 특성(빛이 밝을수록 저항이 일정한 비율로 작아짐)을 이용해 센서값으로부터 추정한 값이에요. 배경 빛을 빼고, 가장 가까운 거리의 값을 100으로 놓고 비교해요.

5개념정리 · 겉보기 등급과 절대 등급

빈칸을 채운 뒤 [정답 확인] 버튼으로 스스로 점검해 보세요. 제출 시 선생님께도 함께 전달됩니다.

(1) 히파르코스는 눈에 가장 밝게 보이는 별을 등급으로, 가장 희미한 별을 등급으로 정하였다. 이렇게 나타낸 밝기 등급을 겉보기 등급이라 한다.
(2) 1등급인 별은 6등급인 별보다 약 배 더 밝고, 등급 사이(한 등급 차이)에는 약 배의 밝기 차이가 있다.
(3) 절대 등급은 모든 별이 지구로부터 같은 거리인 pc에 있다고 가정했을 때의 밝기 등급이다.

배운 내용 정리하기 — 옳으면 O, 옳지 않으면 X를 골라 보자.

1. 겉보기 등급이 클수록 어둡게 보이는 별이다.
2. 태양은 우주에서 절대 등급이 가장 작은 별이다.
3. 거리가 10 pc인 별은 겉보기 등급과 절대 등급이 같다.

6시뮬레이션 · 별을 드래그해 거리를 바꿔 보자

태양, 폴룩스, 데네브를 손가락(또는 마우스)으로 끌어서 지구로부터의 거리를 바꿔 보자. 절대 등급(고정된 값)은 그대로인데, 거리가 바뀌면 겉보기 등급이 어떻게 변하는지 살펴보자. 점선 원은 10 pc 기준선이다.
