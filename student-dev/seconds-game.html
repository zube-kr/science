정밀도 (소수점 자릿수)
표시 자릿수예요. 기록은 항상 소수점 6자리(마이크로초)까지 계산하지만, 실제 측정은 브라우저와 기기 시계의 정밀도를 넘을 수 없어요.
세슘-133 주기 표시
1초 = 세슘-133(¹³³Cs) 원자의 바닥상태에 있는 두 초미세 준위 사이 전이에 해당하는 방사선의 9,192,631,770 주기의 지속 시간 (SI 초의 정의). 켜면 시간이 주기 수로도 표시돼요.
알람 (카운트다운 종료)
100%가 기본(최대 진폭)이에요. 100%를 넘기면 소리가 더 커지지만 깨질 수 있어요.
기본 알람음 사용 중
시간이 끝나면 노래(또는 기본 알람음)가 반복되고, 최대 60초 뒤에 자동으로 멈춰요. "알람 끄기" 버튼이나 스페이스바로 끌 수 있어요. 진동은 진동을 지원하는 기기(주로 휴대폰)에서만 작동해요.
