“내 자리가 어디지?” “이쪽이야!” 생물이 구성되는 단계는 관현악단의 구성과 어떤 공통점이 있을까? 구성 단계 카드를 순서대로 늘어놓고, 가상 확대경으로 사람과 나무를 세포까지 확대해 보자.

🎯 이 단원을 배우면 — 생물의 유기적 구성 단계를 이해하고, 동물과 식물의 구성 단계를 비교·분석하여 설명할 수 있다.

생물은 어떻게 구성되어 있을까?

관현악단은 관악기가 모인 관악기군, 현악기가 모인 현악기군 등 여러 악기군이 모여 이루어진다. 여러 개의 세포로 이루어진 생물도 세포를 기본 단위로, 몇 가지 단계를 거쳐 이루어진다.

준비물 생물의 구성 단계 활동판(부록 263쪽), 카드(부록 265쪽), 풀
  1. 활동판과 카드를 뜯고, 카드는 그림이 위로 오도록 모아 놓는다.
  2. 카드의 그림을 보면서 구성 단계를 예상해 보고, 활동판 위에 친구와 번갈아 카드를 배열한다. (카드를 뒤집지 말고 그림만으로 유추!)
  3. 카드를 뒤집어 설명을 확인하면서 세포 단계에서 개체 단계까지 순서대로 붙인다.

  2. 🧍 사람 — 하나의 독립된 생물
  3. 🔬 상피세포
  4. 🌀 소화계 — 위, 작은창자, 큰창자 등

  1. 🟩 표피조직계 — 표피조직과 공변세포가 모인 것
  2. 🌳 나무 — 하나의 독립된 생물
  3. 🍃 잎 — 표피조직계, 관다발 조직계 등이 모인 것
  4. 🔬 표피세포
  5. 🧱 표피조직

교과서생물의 유기적 구성 단계 49쪽

여러 개의 세포로 이루어진 생물의 구성 단계는 그림 2-3과 같다. 기능이 비슷한 세포들이 모여 조직을 이루고, 여러 조직이 모여 고유한 모양과 기능을 갖춘 기관을 이루며, 기관이 모여 하나의 독립된 생물인 개체가 된다. 동물의 구성 단계에는 관련된 기능을 하는 기관들로 이루어진 기관계가 있다. 식물의 구성 단계에는 몇 가지 조직이 모여 이루어진 조직계가 있다. 이처럼 생물은 일정한 단계를 거쳐 유기적으로 이루어진다.

3생물의 구성 단계

생물은 세포, 조직, 기관, 개체의 단계를 거쳐 유기적으로 이루어진다.
· 동물의 구성 단계: 세포 → 조직 → 기관 → → 개체
· 식물의 구성 단계: 세포 → 조직 → → 기관 → 개체
